# video-to-scratch-converter
simple python script to convert a video into a scratch project

## requirements
|Package|Version|
|---------|-------|
|moviepy|2.2.1|
|opencv-python|5.0.0.93|

## installation
### 1. download latest release
### 2. run these commands in the terminal
```bash
cd path/to/video-to-scratch-converter
py -m venv .venv
.venv\scripts\activate
pip install -r requirements.txt
```
### 3. run the script with the command
```bash
python main.py path/to/video.mp4 path/to/output.sb3
```
